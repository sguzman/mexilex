# Mexilex public gallery

[Open the live dictionary](https://sguzman.github.io/mexilex/) · [Machine-readable gallery index](index.json) · [Published corpus manifest](../corpus/manifest.json)

The gallery points to Mexilex's already-public read-only dictionary and its versioned lexical catalogue. The dictionary's specimens are Spanish lexical entries and source-backed individual meanings, not fabricated example entries or a second copy of third-party corpus data.

Individual senses are marked as Mexican only when that use is explicitly evidenced. Other Spanish entries remain eligible for exploration, and independent regional attestations retain their own provenance and limitations.

Source-derived data has licenses independent of the project's MIT code license; see [corpus attribution](../CORPUS-LICENSE.md).
