# Mexilex agent guidance

Start with [CONSTITUTION.md](CONSTITUTION.md), [README.md](README.md), [docs/architecture.md](docs/architecture.md) and [CORPUS-LICENSE.md](CORPUS-LICENSE.md).

- Use the existing main branch unless directed otherwise. Keep changes limited to the requested task; preserve the current Rust CLI, corpus snapshots, source evidence, website, and documented exports.
- Do not publish private text, accounts, review history, secrets, credentials, unlicensed third-party assets, or confidential source material in any public artifact or Git history. Use neutral, source-backed language.
- Keep individual lexical senses, forms, regional labels, source attestations and uncertainties distinct. Do not infer Mexican usage solely from the project's name, or infer that untagged senses are absent from Mexican Spanish.
- The public corpus derives from English Wiktionary via Kaikki/Wiktextract; its attribution, CC BY-SA/GFDL obligations, and the separately licensed frequency evidence must remain explicit.
- The ontology and gallery are independent pointers to existing public resources, not copies of third-party datasets.
- Only enroll or remove a repository from Tarium when the owner explicitly authorizes that named membership action. Never enroll other repositories by association.
- Run proportionate validation for files modified. Do not claim a deployed website or other successful QA without observed evidence.
