# Mexilex lexical ontology

[Machine-readable ontology](ontology.json) · [Architecture](../docs/architecture.md) · [Corpus manifest](../corpus/manifest.json) · [Source licensing](../CORPUS-LICENSE.md)

Mexilex studies lexical entries and their individual senses as research objects. Each entry can have multiple English-defined senses, forms, usage labels and traceable sources. Regional evidence belongs to the source observation or explicitly labeled sense; a missing Mexico label never means a word is absent from Mexico.

The machine-readable file describes existing project entities, relations and invariants without copying dictionary material. The canonical normalized lexical dataset remains in the existing Git-tracked shards under `corpus/`, while the static dictionary and read-only consumer exports are derived projections.

This is a lexical ontology, not a universal description of language and not a personal spaced-repetition database.
